技術的な設計図（ブループリント）風のイラストを1枚生成してください。

【シーン】濃紺の製図用紙。画面中央に、コンテナを表す箱型の装置を
正面図（立面図）として大きく描く。箱は太い二重線の壁で囲われ、
前面は調整パネルになっている：つまみ（ダイヤル）が横一列に5つ並び、
その上に小さな表示窓が1つある。
箱の周囲に、調整対象を表す小さな部品を5つ配置し、
それぞれから引き出し線を箱のつまみへ引く。部品は次の5つ：
鎖の輪を2つつないだリンク記号、写真を表す額縁状の矩形、
名札を表す小さなタグ、スマートフォンの輪郭、工具箱を表す小さな箱。
部品の一部は箱の外側に置き、線で箱につながっていることを示す。
箱の上に、スパナ（レンチ）を1本、斜めに大きく重ねて描く。
全体に寸法線・引き出し線・中心線が引かれ、設計図として成立している。

【雲雀の署名】添付画像の小鳥を、画面右下の隅に署名として
小さく1羽だけ描く。シルエットは添付画像に厳密に従う
（後方に長く流れる尾・頭頂の冠羽・くちばしの形・翼の形）。
大きく描かない。円形の囲いを付けない。画面の主役にしない。

【画風】製図・設計図の様式。形状は明るいシアンの線画で描き、
面はほとんど塗らない。線は太くはっきりと引く。
背景に薄いシアンの方眼グリッドを広い間隔で敷く。

【色】背景 #0E2A3F / 主線 #7FD4F5 / 補助線とグリッド #2E5C7A /
アクセント #C9B8EA（淡い藤色。スパナの輪郭、5つのつまみ、
寸法矢印のみに使う）。橙・黄・緑・桃色は使わない。

【注記】寸法値や部位名を英数字で入れてよい。日本語は使わない。
注記は小さく控えめにし、画面の主役にはしない。
同じラベルを2箇所以上に重複させない。数値は互いに矛盾させない。
値のない寸法線を描かない。

【構図】被写体は中央帯に置き、上下端から離す。
画面の30%以上を、何も描かない濃紺の余白として残す。
上下の端 3% は後でトリミングされるため、重要な要素を置かない。

【制約】人物を描かない。写真的な質感・影・グラデーション・
3Dレンダリング表現を使わない。文字のロゴやウォーターマークを描かない。
幅400pxに縮小しても主題が判別できる線の太さで描く。
