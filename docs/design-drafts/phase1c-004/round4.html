PHASE1C-004 ラウンド4｜数字レイアウト10案（シェイプ確定用・墨一色）

固定素材：リング = 旧案2のトレース（テーパーの筆致を原本から流用）／鳥 = 冠羽つき短尾（Gemini3 のトレース、旧案2の鳥と同じ占有域に配置）。色の議論を切り離すため全て墨一色。違いは数字（+粒）の構図だけ。数字列は 'b' の ASCII（01100010）の繰り返し。

1｜扇状カスケード — 旧案2の構造を、数を絞って規律化

2｜スウッシュ — 尾から鳥の下をくぐる一本の弧（下線の払い）

3｜円周トレース — ラウンド3の置き方（比較用の基準）

4｜翼の後流 — 翼が破ったリングの欠けから、外へ流れ出す

5｜さえずり — くちばしから昇る（歌＝データ。尾ではなく声から）

6｜重力こぼれ — 腹の下から真下に落ちる。四角い粒（ビット）を混ぜる

7｜上昇気流 — 右下から頭へ、円に沿って数字が昇っていく

8｜後流の直線 — 機体軸の延長線上に、間隔を加速させて

9｜リング白抜き — 筆致の太い区間に数字を刻む（余白の発想）

10｜数字なし — 粒3つだけ。byte はワードマーク側に任せる対照案
