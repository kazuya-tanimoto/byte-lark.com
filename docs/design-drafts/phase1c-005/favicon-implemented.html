ブラウザの実タブそのものは撮影できないため（ヘッドレスにブラウザ枠がない）、これは同じ寸法で組んだ再現です。アイコン自体は実ファイルです。

入っている 3 つのファイル

public/favicon.svg

タブの主役。ベクターなので拡大しても崩れません。

public/favicon.ico

16 と 32 の 2 サイズ入り。rel を見ずに root を直接取りに来る RSS リーダー等のための後方互換です。角丸の外側は透過なので、暗いタブでも四隅が白くなりません。

public/apple-touch-icon.png

180×180、不透明、角丸なし。iOS が自分で角を丸めるため、こちらで丸めて透過を残すと四隅が黒く塗られます。

ヘッダーのロゴとの関係

サイト内のロゴは墨一色のままです。アイコンだけ sky のタイルに載せました。

byte-lark

サイトの中では暖白の地があるので墨一色が映えますが、タブやホーム画面では地の色が使えません。16px で見つけてもらうには塗りのタイルの方が強い、という理由で分けています。形の語彙は同じバッジなので、並べても血縁が見て取れます。
