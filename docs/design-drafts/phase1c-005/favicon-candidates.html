PHASE1C-005 favicon 案比較（実寸）

素材は logo-badge.svg（Gemini7 の簡略鳥 + 切れ目リング）。左がブラウザの明るいタブ、右が暗いタブでの見え方。A+ の色は OS のテーマに追従するため、OS がライトなら左列・ダークなら右列が実際の見え方（ブラウザのタブ地も OS に追従するので、実使用では必ず読める側になる）。

明るいタブ暗いタブ
A 透過 + 墨（ヘッダーと同一）タブ地の色に乗る。暗いタブでは見えなくなるため、下の A+ で自動反転を足す
A+ 透過 + 墨（暗所で自動反転）SVG 内に prefers-color-scheme を持たせ、暗いタブでは暖白に反転
B 暖白タイル + 墨紙のタイル。墨一色の語彙をそのまま保つ
C sky タイル + 白抜きブランド primary。タブでの視認性が最も高い
D 墨タイル + 暖白抜き反転。締まるが色でブランドを想起させる要素がない
E 暖白タイル + 墨鳥 + sun リング朝日リング。design-direction §6 の色指示に最も近いが、墨一色から外れる
