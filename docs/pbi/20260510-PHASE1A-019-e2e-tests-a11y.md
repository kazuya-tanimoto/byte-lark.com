# Claude は E2E テストとアクセシビリティチェックでサイト品質を自動検証できる

Status: NotStarted

## 誰が
- Claude

## 何をできる
- Playwright E2E テストで主要画面遷移と挙動を自動検証できる
- axe によるアクセシビリティチェックで WCAG 2.1 AA 相当の品質を担保できる
- Vitest で React Island と lib/ ロジックの単体テストを実行できる

## なんのために
- 全ページ実装後のリグレッションを自動検出するため
- アクセシビリティの品質基準（WCAG 2.1 AA）を客観的に担保するため
- 関連: site-plan.md NFR-02 / NFR-05 / NFR-06

## 受け入れ条件
- [ ] 既存の Playwright 公式デモテスト（`demo-todo-app.spec.ts` / `example.spec.ts`）を削除
- [ ] `tests/e2e/` 配下に自プロジェクト用の E2E テストを新規作成
- [ ] E2E: 全主要ページ（Home / About / Career / Skills / Blog / Contact / Privacy / 404）への遷移テスト
- [ ] E2E: Blog 一覧 → 記事詳細の遷移テスト
- [ ] E2E: カテゴリフィルタの動作テスト
- [ ] E2E: Header ナビゲーションの動作テスト
- [ ] E2E: 存在しない URL → 404 ページ表示テスト
- [ ] axe チェック: 主要ページで重大エラー（critical / serious）ゼロ
- [ ] Vitest: `src/lib/` のユーティリティ関数のテスト
- [ ] Vitest: CategoryFilter（React Island）のテスト
- [ ] `yarn test:run` 成功（Vitest）
- [ ] `yarn test:e2e` 成功（Playwright、sandbox 外で実行）
- [ ] `yarn check:ts` エラーなし

## 技術メモ
- Playwright は Claude Code sandbox 外で実行する前提（PHASE0-009 / PHASE0-010 申し送り: sandbox でのポート listen 制限）
- axe は `@axe-core/playwright` を使用して E2E テスト内でチェック
- `playwright.config.ts` は Phase 0 で Astro 用に調整済み（設定流用）
- `@axe-core/playwright` は yarn add が必要（運営者の別ターミナルで実行）
