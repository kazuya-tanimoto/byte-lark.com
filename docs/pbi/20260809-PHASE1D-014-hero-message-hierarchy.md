- 名前：42px 太字 → 32px 太字（desktop）。キャッチ：24px → 20px で名前の直下（mt-2）

- ヒバリと点線の位置：変更の前後で同じ

学び・つまずき

- 案出しは「効く軸」を先に見立てて、その軸を振る。1 巡目は並べ方を振ってサイズを固定したため、選定後に本題（圧の強さ）が発覚した
- 複数案の比較は枚数が増えるほど画像の羅列では見られない。スクショを data URI で埋め込んだ比較ページ（Artifact）1 枚にまとめる方が選びやすい
- コピーの強度とサイズは釣り合わせる。汎用的な文を最大サイズで張ると空虚さが目立つ。固有性のある要素（名前・経歴の数字）に声量を割く方が収まる
- 和文の折り返し調整（balance / auto-phrase）は global.css で h1〜h4 だけが対象。p の半端な折り返しは、幅の 1px 不足のような境界条件でも起きる。「なぜこの幅で折れるか」を疑うときは nowrap にして scrollWidth を実測すると早い
- 一時ページを含んだビルドがそのまま `dist/` に残ると preview に露出する。比較用ページを消したら必ず再ビルドしてから撮る
